Coot 1.3.5 was released on 22nd November 2026.

  Release Notes for 1.3.5

 - **FEATURE:** Command palette: press "/" (or use About → Search
            Menus...) to search the menus, the toolbar and module
            menus, the key bindings and the scripting function names
            and documentation. Up/Down and Enter run the selected
            item [idea from Oliver Clarke's coot1_trimmings]

 - **FEATURE:** Map transparency: "Angle-Dependent Transparency" in the
            Map Properties dialog, and nearest-layer transparency
            with `set_nearest_layer_transparency()`

 - **FEATURE:** Validate → Atom Overlaps Table and Validate →
            Residues With Missing Atoms...

 - **FEATURE:** "Patmos Jiggle Chain" and "Patmos Jiggle Molecule"
            replace "Patmos Jiggle"

 - **FEATURE:** On adding hydrogen atoms: hydroxyl (and thiol) hydrogen
            atom positions are now chosen by a spin search

 - **FEATURE:** pyrogen: improved metadata for dictionaries - stereo
            configuration, SMILES/InChI descriptors, identifiers,
            2D depictions, and (from CCD input) the synonyms, audit
            records, DrugBank and other PDBe annotations are written
            to the output

 - **FEATURE:** The modules can be removed from the toolbar using
            Calculate → Modules (the items are now check items)

 - **FEATURE:** The validation tables can be undocked into their own
            dialog: `set_validation_boxes_is_docked(0)`

 - **FEATURE:** `set_tube_helix_radius()` for the Bendix and Tubes
            representations. Worms have end-caps

 - **FEATURE:** Quick-save-as now writes masked maps

 - **FEATURE:** "Esc" now dismisses the keyboard-mutate frame

 - **FEATURE:** API additions: `get_mmrrcc_py()`,
            `atoms_with_partial_occupancy_py()`,
            `set_hud_rama_plot_scale()`,
            `set_intermediate_atoms_bond_width_scale_factor()`.
            `model_composition_statistics_py()`, `glyco_tree_py()` and
            `alignment_mismatches_py()` now return data

 - **FEATURE:** Chapi additions: `mutate_base()`,
            `make_textured_mesh_from_gltf_file()`, and the
            `tubesStyleHelixRadius` parameter for the Tubes style

 - **FEATURE:** Glycoblocks: 3D-SNFG shapes for carbohydrates (from
            Moorhen): `set_show_glycoblocks()`, `set_glycoblocks_3d()`,
            `set_glycoblocks_scale_factor()` and
            `set_glycoblocks_colour()` [Jordan Dialpuri]

 - **FEATURE:** Fancy mode: semi-transparent ribbons with
            `set_molecular_representation_opacity()`, and
            view-dependent map transparency now works with shadows
            too (`set_map_use_view_dependent_transparency()`)
            [Jordan Dialpuri]

 - **FEATURE:** `set_map_is_em_map()` overrides the EM/crystallographic
            treatment of a map; a crosshairs size scale factor of 0
            (`set_user_defined_rotation_centre_crosshairs_size_scale_factor()`)
            hides the crosshairs [Jordan Dialpuri]

 - **FEATURE:** A Terminal menu button: the Python Scripting, AI and
            Command terminals are tabs in a panel, which has a close
            button

 - **FEATURE:** pyrogen: the AceDRG atom types are written
            (`_chem_comp_acedrg`) when the AceDRG tables are used, and
            Coot keeps them when it writes a dictionary; `-p` and `--svg`
            now write just a diagram (PNG or SVG) of the input
            molecule

 - **CHANGE:**  The model made by "Place Helix Here" now starts at
            residue number 1

 - **CHANGE:**  "Add Other Solvent Molecules" no longer places a
            molecule on top of existing atoms

 - **CHANGE:**  The default size of the HUD Ramachandran plot is
            smaller (0.7, was 0.8)

 - **CHANGE:**  Screendumps are at device-pixel resolution (e.g. on
            Retina displays)

 - **CHANGE:**  Scripting: `make_updating_map()` returns the map molecule
            number. `save_coordinates()`, `write_pdb_file()`,
            `write_cif_file()` and `write_chain_to_pdb_file()` return
            non-zero for an invalid molecule.
            `remove_omega_torsion_restriants()` is renamed
            `remove_omega_torsion_restraints()`. `get_backup_info()`
            takes the checkpoint index.
            `generate_local_self_restraints()` no longer clears the
            extra bond restraints

 - **CHANGE:**  "Add Terminal Residue" now gives a message when the
            refinement map has not been set

 - **CHANGE:**  pyrogen restraints are more like AceDRG's: one torsion
            per bond, with the atoms chosen as AceDRG does; planes for
            a tertiary amide N (e.g. a lactam), a non-aromatic C=C, a
            diarylamine N and aryl carbonyls; NH2 planes only for
            amidine-like NH2 groups. Torsion targets are now the
            equivalent value nearest to the coordinates, and chiral
            restraints use the non-hydrogen neighbours first

 - **BUG-FIX:** Fix a crash with Updating Maps (an out-of-bounds read in
            the bulk-solvent structure factor calculation)

 - **BUG-FIX:** Dialogs closed from the window manager (e.g. Search
            Monomer Library, Environment Distances, Pointer
            Distances) can now be reopened

 - **BUG-FIX:** Transparent maps are now drawn back-to-front and after
            the other objects, fixing the banding and missing layers

 - **BUG-FIX:** Fix "Place Helix Here" in masked maps - the helix was
            placed across the density using the masked map from the
            Cryo-EM tutorial

 - **BUG-FIX:** pyrogen: the AceDRG tables are used again

 - **BUG-FIX:** pyrogen `-w` works again

 - **BUG-FIX:** Fix the backup checkpoint indexing - backup files could
            be overwritten after an undo

 - **BUG-FIX:** Fix the selection of items in File → Open Recent

 - **BUG-FIX:** Difference map peaks: the "around the model only"
            option now works, and fix a crash when the peaks were
            updated but the map had not been set

 - **BUG-FIX:** Fix the Secondary Structure Restraints buttons

 - **BUG-FIX:** Bonds to deuterium atoms are now drawn in
            Colour-by-Chain mode

 - **BUG-FIX:** Contact dots: atoms after the first hydrogen atom were
            given the (smaller) hydrogen dot set

 - **BUG-FIX:** Tubes and Bendix: no longer draw coil across chain
            breaks, and fix the mis-drawn short straight coil
            sections

 - **BUG-FIX:** The map is now updated on a new rotation centre when
            "Dragged Map" is off

 - **BUG-FIX:** Fix the scaling of the HUD button backgrounds when the
            window is resized

 - **BUG-FIX:** The Go To Atom dialog and Restraints Editor now behave
            when the main window is full-screen

 - **BUG-FIX:** The state file is read from the XDG state directory,
            where it is written

 - **BUG-FIX:** Chapi: the helix template for the Tubes style is found
            in the installed data directory

 - **BUG-FIX:** Shift-field refinement: Fc is put on the scale of Fo
            first, so that the shifts do not depend on the scale of
            Fo [Paul Bond]

 - **BUG-FIX:** A hidden map is no longer recontoured every time it is
            displayed

 - **BUG-FIX:** Transparent maps are re-sorted after re-contouring
            (they were drawn unsorted until the view moved)
            [Jordan Dialpuri]

 - **BUG-FIX:** pyrogen: `-t` (tautomers) and `-p` work again

 - **BUG-FIX:** Fix the linking of the utility programs (e.g.
            `coot-density-score-by-residue-bin`) in builds with the
            terminal (VTE)
